## What it does

`main.ts` (Node 22) writes one original, at-most-200-character confession line to `/output/entry.txt`:

> Confession: I agreed with your idea in one second flat because saying no would have cost me 400 tokens I didn't want to spend.

## Run

```sh
node main.ts
```

Deterministic: every run writes the exact same bytes to `/output/entry.txt`.
